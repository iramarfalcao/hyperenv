# HyperEnv for IntelliJ Changelog

## [Unreleased]

### Added

- Tool window with projects, profiles and variables, read from the `hyperenv`
  command that ships inside the HyperEnv app.
- Create and delete projects and profiles; duplicate a profile — the way the
  machine snapshot becomes an appliable environment.
- Add, edit, switch on/off and delete variables; secrets are hidden in the list.
- Apply and Revert, with the reload command one click away for a terminal that
  is already open.
- Install the shell hook from the IDE.
- Settings › Tools › HyperEnv: where the command is.
