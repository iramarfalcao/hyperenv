# Monetização — HyperEnv

> Hipótese de trabalho, não decisão fechada. Números aqui mudam; quando mudarem,
> atualize também o `STATUS.md` e a linha de monetização do site.

## Modelo

**Gratuito e open source (MIT).** Sem plano pago, sem assinatura, sem versão Pro.

## Preço

Zero. O código é público e a build oficial também.

## O que fica de graça

Tudo.

## Por que assim

Um app que escreve o arquivo lido no login do seu shell precisa ser auditável para merecer confiança. Cobrar
por ele reduziria a adoção justamente entre quem sabe ler o código — o público que o valida. O retorno aqui é
reputação e porta de entrada para os apps pagos do estúdio, não receita direta.

## O que precisa estar pronto para cobrar

Não se aplica. Se um dia houver versão paga, ela será um recurso de equipe (perfis compartilhados), nunca o básico.
