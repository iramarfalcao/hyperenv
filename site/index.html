HyperEnv

Your environment, in the right place.

Environment variables organised per project and per environment. Switch the whole set in one click — and put the previous values back when the switch turns out to have been a bad idea.

A closer look

One engine, four places to reach it.

01

Profiles per project

A profile for each project and each environment, so dev, staging and production stop sharing one file and one accident.

02

A risk class on each profile

Production is marked as production. The app knows which switch deserves a second look before it happens.

03

Undo in one click

Applying records what was there before. When the switch was wrong, the previous values come back without you reconstructing them from memory.

04

The hyperenv command

Shipped inside the app, on the same core, store and journal. One engine, one writer in ~/.zprofile — not two tools disagreeing.

Install

One command, and you have it.

Homebrew if you have it, the disk image if you do not. It verifies the published checksum, never uses sudo, and you can read it before you run it.

curl -fsSL https://hyperenv.falcaosl.com/install.sh | bash

Read the script first — it is forty lines, and running something piped into a shell without looking is a bad habit this project does not want to encourage.

Preview · HyperEnv 2

Now on Linux and Windows too.

HyperEnv 2 brings the app to Windows and Linux, and the hyperenv command to all three systems: the same profiles, the same apply and undo. zsh, bash and fish write to your startup file; on Windows it goes to your user environment. It is a pre-release, and it does not replace the macOS app above yet.

The app — for Windows, a per-user installer (no administrator); for Linux, a .deb or an AppImage. Get it from the latest HyperEnv 2 preview.

The command, for scripts and the editor plugins:

macOS and Linux — installs to ~/.local/bin, no sudo:

curl -fsSL https://hyperenv.falcaosl.com/install-cli.sh | sh

Windows PowerShell — installs for your user only, no administrator:

irm https://hyperenv.falcaosl.com/install.ps1 | iex

Both check the SHA-256 published with the release. Read them first: install-cli.sh · install.ps1. Or download the binary yourself — Linux x86_64 and ARM64, Windows x64 and ARM64, and one universal macOS build — from the GitHub releases.
